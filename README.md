## Descrição do projeto

O projeto consiste em um sistema web para controle de despesas pessoais, desenvolvido com HTML, CSS e JavaScript.

O sistema foi desenvolvido com a temática da Fundação SpeedWagon, inspirada no universo de JoJo's Bizarre Adventure, utilizando essa identidade visual para tornar a aplicação mais personalizada.

## Funcionalidades

- Cadastro de despesas;
- Validação dos dados do formulário;
- Listagem de despesas;
- Pesquisa por descrição;
- Filtro por status;
- Visualização dos detalhes de uma despesa;
- Alteração do status entre paga e pendente;
- Dashboard com resumo das despesas;
- Gráfico de despesas por status;
- Gráfico de despesas por categoria;
- Atualização da interface sem recarregar a página;
- Carregamento inicial simulado de forma assíncrona.
